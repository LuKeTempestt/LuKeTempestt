## Projeto principal

### Nexo Pessoas

[![Tela de gestão de usuários do Nexo Pessoas](https://raw.githubusercontent.com/LuKeTempestt/nexo-pessoas/main/docs/screenshots/usuarios.jpg)](https://nexo-pessoas.vercel.app)

O Nexo Pessoas nasceu de um CRUD de usuários e evoluiu para uma plataforma de gestão do ciclo de vida de cadastros. O produto reúne:

- autenticação e controle de acesso por perfis;
- ativação, desativação, exclusão lógica, restauração e exclusão permanente;
- trilha de auditoria, proteção CSRF e limitação de requisições;
- frontend em React e TypeScript integrado a uma API Python com FastAPI;
- PostgreSQL e Redis, com ambiente local reproduzível por Docker Compose;
- 60 testes automatizados, integração contínua e análise de segurança com CodeQL.

[Aplicação](https://nexo-pessoas.vercel.app) · [Código](https://github.com/LuKeTempestt/nexo-pessoas) · [Arquitetura](https://github.com/LuKeTempestt/nexo-pessoas/blob/main/docs/ARQUITETURA.md) · [Versão atual](https://github.com/LuKeTempestt/nexo-pessoas/releases/latest)
